## 💎 WHAT MAKES EBOLT SPECIAL?

| Feature | Experience |
|---|---|
| 🎨 Modern Interface | A polished dark theme with cyan highlights and glass-inspired styling. |
| 📝 Notes Workspace | Create, edit, organize, and manage notes. |
| 💾 Local Data Storage | Keep supported notes and profile data in your browser. |

```bash
cd Ebolt-website
```

Open `index.html` in your browser.

## 🔒 A QUICK SECURITY NOTE

The static website uses browser-based storage for supported data. Information stored this way is specific to the browser and device and does not automatically synchronize between devices. The frontend login interface should not be treated as secure production authentication.
