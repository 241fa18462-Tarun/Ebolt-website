1. Clone this repository:

   ```bash
   git clone https://github.com/241fa18462-Tarun/Ebolt-website.git
   ```

2. Open the project folder:

   ```bash
   cd Ebolt-website
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.
