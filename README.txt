## 🌟 About EBOLT

**EBOLT** is a modern web-based workspace designed to provide a smooth and focused environment for writing, saving, managing, and revisiting your notes.

Featuring a sleek dark interface, elegant glass-style panels, cyan highlights, and smooth animations, EBOLT combines a premium visual experience with useful everyday productivity features.

Whether you're capturing quick thoughts, organizing important information, or managing personal notes, EBOLT gives your ideas a place to live.

## ✨ Key Features

- 🔐 **Sign In & Sign Up** — Interactive account access and registration interface.
- 📝 **Smart Notes Workspace** — Create, write, edit, and manage your personal notes.
- 💾 **Save Your Notes** — Keep notes available in your browser for future visits.
- ➕ **Create New Notes** — Start fresh notes whenever inspiration strikes.
- 🔍 **Note Management** — Search, sort, copy, edit, and delete notes with ease.
- 👤 **Personal Profile** — View and update personal information, including date of birth, age, gender, country, and state or province.
- 🤖 **AI Chatbot Interface** — An assistant-themed sidebar entry for a more modern workspace experience.
- 🎨 **Premium UI Design** — Dark navy colors, glowing cyan accents, glass-inspired panels, and smooth transitions.
- 🌌 **Animated Background** — A subtle looping video background with pointer, touch, and device-orientation effects.
- 📱 **Responsive Experience** — A layout designed to adapt to different screen sizes.
- ⚡ **Lightweight & Simple** — Built with HTML, CSS, and JavaScript without requiring a build process.

## 💻 Run Locally

Want to explore or modify the project on your computer?

1. Clone the repository:

   ```bash
   git clone https://github.com/241fa18462-Tarun/Ebolt-website.git
   ```

2. Open the project folder:

   ```bash
   cd Ebolt-website
   ```

3. Open `index.html` in your browser.

That's it! No build tools or package installation are required for the static website.

## 🌐 Deployment

EBOLT is published using **GitHub Pages**.

To publish your own changes:

1. Push your updated files to the repository.
2. Open your repository's **Settings → Pages**.
3. Select the `main` branch and the root folder as the publishing source, if not already configured.
4. Save your settings and visit your published website.

## 💡 Why EBOLT?

EBOLT focuses on bringing together **simplicity, productivity, and modern design** in one convenient web experience.

- ✨ Clean and visually engaging interface
- 📝 Easy-to-use note management
- 👤 Personalized workspace information
- 🌌 Subtle animations and polished interactions
- ⚡ Simple deployment and lightweight frontend architecture

## 🔒 Important Note

EBOLT's current static version stores its account information, notes, and profile data in browser Local Storage. This means the data is browser-specific and is not automatically synchronized across devices.

It is a frontend demonstration, not a production-secure authentication system. Avoid using real passwords or sensitive personal information.
