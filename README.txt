## ✨ Features

- 🔐 **Account screens** — sign-in and sign-up interface, with remember-me and password recovery links.
- 📝 **Quick writing workspace** — start writing directly from Home or open the full note editor.
- 💾 **Saved Notes** — save ideas, reopen them, create separate notes, and keep your work organized.
- ✏️ **Note editing tools** — create, rename, clear, and save notes.
- 🤖 **AI Chat Bot** — a chat-style assistant interface for help with ideas and writing.
- 👤 **User Info profile** — view and edit profile details such as date of birth, age, gender, country, and state/province.
- 🌊 **Animated background** — subtle looping video background with pointer/touch/device-orientation movement.
- 🎨 **Distinct visual design** — dark workspace, teal/blue accents, rounded panels, and panda branding.

## 🧰 Built With

- **HTML5** for page structure
- **CSS3** for layout, styling, and responsive presentation
- **Vanilla JavaScript** for workspace interactions
- **Browser localStorage** for locally saved notes and profile details
- **GitHub Pages** for hosting

## 🚀 Run Locally

No build tools or package installation are required.

1. Download or clone this repository.
2. Keep `index.html`, `styles.css`, `main.js`, and the `assets/` folder together.
3. Open `index.html` in your browser.

```bash
git clone https://github.com/241fa18462-Tarun/Ebolt-website.git
cd Ebolt-website
```

Then open `index.html`.

## 💾 Data & Privacy Notes

- Notes and profile details are stored in the browser's `localStorage` on the device/browser where you use Ebolt.
- Clearing browser site data can remove locally stored information.
- Local browser storage does not automatically sync notes across devices or browsers.
- The animated background video is located at `assets/live-circle.mp4`. Keep the `assets/` folder beside `index.html`.
